# 🌐 Portfolio II

A **modern portfolio website** built with [Next.js](https://nextjs.org/), [TypeScript](https://www.typescriptlang.org/), and [Tailwind CSS](https://tailwindcss.com/).

## ✨ Features
- ⚡ Built with Next.js, TypeScript, and Tailwind CSS  
- 📂 Local image hosting for faster performance and reliability  
- 🎨 Modern, responsive, and clean design  
- 🔍 SEO-friendly with optimized assets  

## 📸 Image Hosting Setup

This project is fully configured to use **local image hosting** instead of external services (like Imgur).  

### ✅ Completed Setup
All project images are stored in `public/` and served locally:
- `/re-true/` – RE-TRUE project images  
- `/passion-for-performance/` – Passion for Performance  
- `/titans-of-japan/` – Titans of Japan  
- `/gt-cap/` – GT Cap  
- `/logo-designs/` – Logo designs  
- `/alsa/` – ALSA  
- `/motion-graphics/` – Motion graphics  
- `/dp1.gif` – Profile picture  
- `/hero-animation.gif` – Hero animation  


### 🚀 Benefits
- **Performance** → Faster loading, better caching, fewer external dependencies  
- **Reliability** → No risk of broken external links  
- **SEO** → Improved Core Web Vitals, better rankings
